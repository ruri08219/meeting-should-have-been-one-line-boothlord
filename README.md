Entry for the [make.fun](https://make.fun) competition
[The Meeting That Should Have Been One Line](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c)
— one line (at most 200 characters): the single sentence that could have
replaced an entire pointless meeting.

## The entry

> We spent forty minutes deciding who should send the email, and the email was: this meeting could have been an email.

116 characters, one sentence, no trailing newline. The meeting's entire
output was one email — and the email's content is the punchline.

## Run it

```sh
python3 src/main.py
```

Writes `entry.txt` to `$OUTPUT_DIR` (default `/output`). Exits 0 on a valid
entry; exits 1 (writing nothing) on an empty, over-long, multi-line, or
control-character entry.
